BLEACH VS NARUTO

Bản Việt hóa toàn diện + chế độ Online 1vs1 trong game (không cần web)

1. Tải bản chơi

Vào mục Releases của repo này, tải file Game-VN-Online.zip, giải nén rồi chạy ChoiGame.bat (tự mở server + game).

Tải game (Releases) Mã nguồn

Yêu cầu: Windows 64-bit. Lần đầu mở port 21337 khi firewall hỏi thì bấm Allow.

2. Chơi online 1vs1

  1. Máy chủ: menu CREATE LOBBY → nhập tên → Tạo phòng → gửi mã phòng 6 ký tự cho bạn.
  2. Máy khách: menu PLAY ONLINE → nhập tên + IP máy chủ → Tìm phòng.
  3. Chủ phòng bấm Bắt đầu. Mỗi người điều khiển nhân vật của mình.

Chung nhà/chung VPN: dùng IP nội bộ (VD: 192.168.1.10). Khác nhà: máy chủ port-forward TCP 21337 hoặc cùng vào Radmin VPN / ZeroTier.

3. Tự host server netplay

Server nằm ở netplay-server/ (Node.js, 0 dependency):

  • Chạy local: node server.js 21337
  • Deploy công cộng: dùng sẵn Dockerfile + fly.toml (Fly.io) hoặc Railway từ repo này.

Sau khi có địa chỉ server công cộng, sửa hằng số NET_PUBLIC trong flash/swf-edits/FighterTester.as rồi import lại vào SWF bằng FFDec (xem flash/BUILD.md).
